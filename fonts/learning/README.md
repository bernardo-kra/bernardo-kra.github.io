# Fontes do estudo Bastidores de uma interface

As fontes são servidas localmente apenas quando a página `/learning` é carregada.

- `display.ttf`: Luckiest Guy, de Brian J. Bonislawsky / Astigmatic. [Origem e atribuição](https://github.com/google/fonts/tree/main/apache/luckiestguy). Licença Apache 2.0 em `display-LICENSE.txt`.
- `body.ttf`: Nunito, de Vernon Adams, Cyreal e Jacques Le Bailly. [Origem e atribuição](https://github.com/google/fonts/tree/main/ofl/nunito). SIL Open Font License em `body-LICENSE.txt`.

Arquivos obtidos da API oficial do Google Fonts. Nenhum arquivo de imagem, logo ou personagem da referência visual foi incorporado.
